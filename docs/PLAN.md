配套文档：[DESIGN.md](DESIGN.md) · 评审通过后按 M0→M5 顺序实施，每个里程碑结束做一次可运行的提交与验收。

## 里程碑总览

| 里程碑 | 内容 | 交付物 | 预估 | 验收标准（可自动化部分必须脚本化） |
|--------|------|--------|------|-----------------------------------|
| **M0** | 工程骨架 | CMake + 目录结构 + 一个能起托盘的空白程序 + clang-format + deploy 脚本 | 0.5 d | `cmake --build` 成功；运行后托盘出现图标、进程常驻、内存 < 25 MB |
| **M1** | 采集与统计内核 | RawInputWindow / KeyEventPump / KeyCatalog / CounterEngine / CorrectionTracker / StatsStore / StatsQuery | 1.5 d | 注入 10 000 次按键 → DB 中 `press` 精确匹配、`corr` 符合归因规则；空闲 10 分钟 CPU 采样为 0.0%；热路径基准 < 2 µs；断电模拟（kill 进程）后数据完整（除最后 15 s） |
| **M2** | 布局引擎 + 热力图 | LayoutRepository + 三套内置布局 JSON + KeyboardHeatmapWidget + HeatRamp | 1.5 d | 三布局切换立即生效；同一份数据在 104/87/68 上都能正确点亮；0 计数键无色；100%/150%/200% 缩放下边缘锐利；窗口缩放不模糊 |
| **M3** | 主窗口与统计视图 | 周期分段控件 + 4 张卡片 + 趋势图 + Top 榜 + 悬停/钻取 + 时段分布 | 1.5 d | 五个周期切换 < 50 ms（含首次查询）；数值与 DB 手工核对一致；悬停/点击交互正确；空状态友好 |
| **M4** | 系统集成 | 托盘菜单 + 自启 + 单实例 + 暂停 + 设置/关于 + 关闭到托盘 + 休眠/锁屏 flush | 1 d | 自启开关能真实读写注册表并在重启后生效；第二次启动不产生第二个进程；暂停期间计数不增长、恢复后正常；锁屏/休眠后数据不丢 |
| **M5** | 打磨与发布 | 主题（深/浅/跟随系统）+ 图标资源 + 动画 + CSV/PNG 导出 + 打包 | 1.5 d | 30 分钟长跑内存曲线平稳、无句柄泄漏；`dist/keyCounter` 在干净用户环境下双击即可运行（含 qsqlite 驱动）；任务管理器无异常占用 |

合计约 **7.5 人日**（不含后续扩展）。每个里程碑提交一次，commit 信息遵循 Conventional Commits。

## M1 细分（风险最高，先做）

1. `KeyCatalog`：pid 编解码 + 伪事件过滤 + `MapVirtualKeyEx` 补充 VK（纯函数，先写单测）
2. `RawInputWindow`：不可见消息窗口 + 注册/注销 Raw Input + `nativeEventFilter` 接入
3. `KeyEventPump`：RAWKEYBOARD → 结构化事件 + 按下位图去自动重复
4. `CounterEngine`：日批次（定长数组）+ `dayDeadline` 摊销日期判断 + 脏标记
5. `CorrectionTracker`：环形缓冲 + 归因规则
6. `StatsStore`：QThread + schema v1 + 预编译 upsert + 事务 + quick_check + 备份 + 损坏隔离
7. `StatsQuery`：区间聚合 + LRU 缓存 + 版本失效
8. 无 UI 的验证入口：`keyCounter --dump today` 打印明细（便于验收与回归）

## 待用户确认的开放项（可在实施中随时调整）

| 项 | 默认取值 | 说明 |
|----|----------|------|
| 错误统计口径默认值 | **归因口径**（哪个键最常被打错） | 字面口径（删除键次数）在设置中可切换 |
| 周起始日 | 周一 | 可改周日 |
| 主题默认 | 跟随系统 | — |
| 热力色带默认 | Ember（青→绿→黄→橙→红→深红） | 备选 Inferno / 色盲友好 |
| 是否需要「时段分布」图 | 是（数据照常采集，UI 在 M5 完善） | 若不需要可从 schema 去掉 `day_hour` |
| 是否需要 CSV/PNG 导出 | 是（M5） | 可延后 |
| 全局热键唤起面板 | 不做 | `RegisterHotKey` 会吞掉系统组合键 |
| 安装包（NSIS/MSI） | 不做，仅绿色目录 | 后续可加 |

## 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 提权窗口（管理员 CMD 等）按键统计不到 | 数据不完整 | 文档明确说明；v1.1 提供「任务计划程序 + 最高权限」可选方案（需一次 UAC） |
| 某些独占/反作弊游戏收不到 Raw Input | 个别场景漏统计 | 先验证；必要时提供「兼容模式」回退 `WH_KEYBOARD_LL`（默认关闭） |
| Fn 键无系统键码 | 无法统计 | 布局中标注「不可统计」，UI 上明确灰显 |
| 用户误以为软件在"记录输入内容" | 信任问题 | 首启动引导页 + 关于页清晰声明：只存聚合计数、不存序列、不联网；提供一键清空与数据目录直达 |
| 提高频统计被安全软件拦注册表写入 | 自启失效 | 读取真实注册表值并提示；失败时给出可复制的命令行与手动步骤 |
| 长时间运行内存/句柄泄漏 | 常驻体验差 | M5 做 30 分钟 soak + 句柄计数对比；批次结构全部定长 |
| 时钟回拨/时区切换 | 统计错位 | 计时用 `dayDeadline` + 日历日归属；异常写 `meta.clock_anomaly` 计数，不做静默修正 |

## 首个提交之后的工作流

1. 每个里程碑一个分支（`feat/m1-core`）+ 一个 PR（自审通过后合并到 `main`）
2. 提交前：`clang-format`（配置见仓库根 `.clang-format`）+ 单测通过 + `bench_*` 不超预算
3. `main` 上打 tag：`v0.1.0-m1` … `v1.0.0`
4. 需求变更先改 `docs/DESIGN.md`，再改代码（文档与实现同步）
