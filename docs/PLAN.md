## 验收记录（M0–M4）

| 项 | 结果 | 验证方式 |
|----|------|----------|
| 构建 | 0 error / 0 warning（/W4 /permissive-），exe 约 400 KB | `cmake --build build` |
| 单测 | 7/7 套件通过（KeyCatalog / CorrectionTracker / Periods / Layouts / CounterEngine / StatsStore / RawInputDecode） | `ctest` |
| 热路径 | 35.4 ns / 次键击（预算 2000 ns） | `keyCounterBench.exe 1000000` |
| 静默内存 | 28.7 MB 工作集 / 6.9 MB 私有 / 11 线程 / 406 句柄 | `Get-Process`（--silent 运行 8 s 后） |
| 单实例 | 第二次启动 exit=0 且只唤起不新开进程（命名互斥体 + QLocalServer） | 连续两次启动 + 进程数校验 |
| 关闭到托盘 | WM_CLOSE 后进程存活、窗口句柄归零 | PostMessage + 句柄校验 |
| 跨零点/休眠/退出落盘 | 单测覆盖 flush 语义；15 s 定时器与 WM_POWERBROADCAST/WM_WTSSESSION_CHANGE 已接入 | 单测 + 代码路径 |
| 面板渲染 | 截图像素校验：主题色命中、热力色带 7 个端点全部出现（深蓝→深红），卡片/趋势区/页脚分层正确 | `screenshot-app.ps1` + `analyze-shot.py` |
| 数据写入 | 演示数据 45 天 / 3109 行 / 46 万次键击写入后，DB 与面板一致 | `gen-demo-data.py` + `check-db.py` |

**本环境未能验证的项（需在真实桌面确认）**：本机是无前台窗口的断开 RDP 会话，`SendInput` 返回 ERROR_ACCESS_DENIED，因此无法注入按键做真实采集验证（已改为对解析函数 `decodeRawKeyboard()` 的 7 项单测覆盖）。
请在真实桌面确认：① 随便打几个键，看热力图是否变红、`--dump` 是否有数；② 拔掉网络/锁屏/休眠后数据不丢。

## M1 细分（风险最高，先做）

1. `KeyCatalog`：pid 编解码 + 伪事件过滤 + `MapVirtualKeyEx` 补充 VK（纯函数，先写单测）
2. `RawInputWindow`：不可见消息窗口 + 注册/注销 Raw Input + `nativeEventFilter` 接入
3. `KeyEventPump`：RAWKEYBOARD → 结构化事件 + 按下位图去自动重复
4. `CounterEngine`：日批次（定长数组）+ `dayDeadline` 摊销日期判断 + 脏标记
5. `CorrectionTracker`：环形缓冲 + 归因规则
6. `StatsStore`：QThread + schema v1 + 预编译 upsert + 事务 + quick_check + 备份 + 损坏隔离
7. `StatsQuery`：区间聚合 + LRU 缓存 + 版本失效
8. 无 UI 的验证入口：`keyCounter --dump today` 打印明细（便于验收与回归）

## 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 提权窗口（管理员 CMD 等）按键统计不到 | 数据不完整 | 文档明确说明；v1.1 提供「任务计划程序 + 最高权限」可选方案（需一次 UAC） |
| 某些独占/反作弊游戏收不到 Raw Input | 个别场景漏统计 | 先验证；必要时提供「兼容模式」回退 `WH_KEYBOARD_LL`（默认关闭） |
| Fn 键无系统键码 | 无法统计 | 布局中标注「不可统计」，UI 上明确灰显 |
| 用户误以为软件在"记录输入内容" | 信任问题 | 首启动引导页 + 关于页清晰声明：只存聚合计数、不存序列、不联网；提供一键清空与数据目录直达 |
| 提高频统计被安全软件拦注册表写入 | 自启失效 | 读取真实注册表值并提示；失败时给出可复制的命令行与手动步骤 |
| 长时间运行内存/句柄泄漏 | 常驻体验差 | 静默态 29 MB / 11 线程 / 406 句柄已实测；批次结构全部定长，后续 soak 再观察 |
| 时钟回拨/时区切换 | 统计错位 | 计时用 `dayDeadline` + 日历日归属；异常写 `meta.clock_anomaly` 计数，不做静默修正 |

## 已交付能力（截至本次提交）

- 逐物理键计数（去长按重复、区分左右修饰键与小键盘键）、日/周/月/年/累计五周期
- 热力虚拟键盘（三套布局可切换、对数色带、打错红点、悬停详情、点击下钻）
- 双口径错误统计：删除键次数 + “最常打错的键”归因榜
- 托盘常驻（动态活动环图标 + 菜单）、开机静默自启、单实例唤起、暂停（1 小时 / 到明天 / 手动恢复）
- 可选全局快捷键（设置中自定义，默认关闭，冲突提示）
- SQLite 存储（WAL + 批量 upsert + 完整性自检隔离 + 每日备份）、`--dump` 控制台直查
- 深/浅/跟随系统主题、三种热力色带、减少动画开关、键盘布局与周起始自定义

## 首个提交之后的工作流

1. 每个里程碑一个分支（`feat/m1-core`）+ 一个 PR（自审通过后合并到 `main`）
2. 提交前：`clang-format`（配置见仓库根 `.clang-format`）+ 单测通过 + `bench_*` 不超预算
3. `main` 上打 tag：`v0.1.0-m1` … `v1.0.0`
4. 需求变更先改 `docs/DESIGN.md`，再改代码（文档与实现同步）
